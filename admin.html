Панель керування

Публікація записує зміни напряму у файл posts.json твого репозиторію, а сповіщення летить у Discord через вебхук.

Доступ до GitHub

Токен зберігається лише у твоєму браузері (localStorage). Як створити — дивись README.

Мої платформи

Встав посилання на свої канали. Це не пароль і не OAuth — просто посилання, яке буде використовуватись у сповіщеннях і на кнопках нижче.

Створюється в Discord: Налаштування каналу → Інтеграції → Вебхуки → Новий вебхук → Скопіювати URL.
