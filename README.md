# Журнал ефіру — простий сайт для новин, стрімів і відео

Статичний сайт на GitHub Pages. Публікуєш пости прямо через форму в браузері —
без окремого сервера чи бази даних. Дані зберігаються у файлі `posts.json`
у твоєму ж репозиторії.

## Що є у файлах

- `index.html` — публічна сторінка, яку побачать усі (посилання й кидатимеш у Discord/Telegram)
- `admin.html` — форма для публікації нових записів (тільки для тебе)
- `posts.json` — файл з усіма записами (редагується автоматично через admin.html)
- `config.js` — сюди треба вписати назву свого репозиторію
- `style.css` — оформлення

## Крок 1. Створи репозиторій на GitHub

1. Зайди на [github.com](https://github.com) і зареєструйся/увійди.
2. Натисни **New repository**.
3. Назви його, наприклад, `news-feed`. Постав галочку **Public**.
4. Створи репозиторій (без README — просто порожній).

## Крок 2. Заливай файли

Найпростіше — прямо через веб-інтерфейс:
1. Відкрий свій новий репозиторій → **Add file → Upload files**.
2. Перетягни туди всі файли з цього набору (`index.html`, `admin.html`,
   `posts.json`, `config.js`, `style.css`, `README.md`).
3. Натисни **Commit changes**.

## Крок 3. Заповни config.js

Відкрий файл `config.js` у репозиторії (олівець для редагування прямо в GitHub)
і встав свої дані:

```js
const SITE_CONFIG = {
  OWNER: "твій-нікнейм-на-github",
  REPO: "news-feed",
  BRANCH: "main",
};
```

`BRANCH` зазвичай `main` — якщо у тебе `master`, встав `master`. Збережи (Commit changes).

## Крок 4. Увімкни GitHub Pages

1. У репозиторії відкрий **Settings → Pages**.
2. У розділі **Build and deployment → Source** вибери **Deploy from a branch**.
3. Branch: `main`, папка `/ (root)`. Збережи.
4. За хвилину-дві сайт з'явиться за адресою:
   `https://твій-нікнейм.github.io/news-feed/`

## Крок 5. Створи токен доступу (щоб публікувати пости)

1. Зайди в **GitHub → Settings (акаунта) → Developer settings → Personal access tokens → Fine-grained tokens**.
2. **Generate new token**.
3. Repository access → **Only select repositories** → вибери свій `news-feed`.
4. Permissions → **Repository permissions → Contents → Read and write**.
5. Створи токен і **скопіюй його одразу** (GitHub покаже його лише один раз).

## Крок 6. Публікуй

1. Відкрий `https://твій-нікнейм.github.io/news-feed/admin.html`.
2. Встав токен у поле вгорі (він збережеться тільки в твоєму браузері).
3. Заповни форму (тип, заголовок, опис, посилання) → **Опублікувати**.
4. За кілька секунд запис з'явиться на головній сторінці `index.html`.
5. Кидай посилання на головну сторінку в Discord/Telegram.

## Важливо про токен

- Токен ніколи не потрапляє у файли репозиторію — він лежить лише в
  localStorage твого браузера. Не вводь його на чужому/спільному комп'ютері.
- Якщо токен «засвітився» — просто видали його в налаштуваннях GitHub і
  створи новий.
- Доступ до `admin.html` нічим не захищений, крім того, що ти єдиний, хто
  знає свій токен — сторінка публічна, як і решта сайту. Якщо хочеш
  сильнішого захисту, можна пізніше додати пароль через сервіс типу
  Cloudflare Access (не обов'язково для старту).

## Як видалити пост

На сторінці `admin.html` внизу є список наявних записів із кнопкою
«Видалити» біля кожного.

## Платформи (YouTube / TikTok / Twitch) і сповіщення в Discord

Важливо розуміти, як це працює: сайт **не логіниться** в твої акаунти
YouTube/TikTok/Twitch (справжня OAuth-інтеграція вимагає окремого сервера
із секретними ключами, чого немає в чистому GitHub Pages). Натомість:

1. У розділі **«Мої платформи»** на `admin.html` ти один раз вставляєш
   посилання на свій канал YouTube, профіль TikTok і канал Twitch.
   Вони зберігаються тільки в localStorage твого браузера.
2. Там-таки вставляєш **Discord Webhook URL**:
   - Discord → налаштування потрібного каналу → **Integrations → Webhooks**
   - **New Webhook** → дай назву, обери канал → **Copy Webhook URL**
3. Тепер кнопки **«🔴 Повідомити про трансляцію»** та
   **«🎬 Повідомити про відео»** відкривають форму, де можна вибрати одну
   чи кілька платформ (чіпи з'являються, тільки якщо посилання на них
   збережено), вписати заголовок, опис і пряме посилання на трансляцію/відео.
4. При публікації запис одночасно:
   - додається у стрічку на `index.html`;
   - надсилається як гарне повідомлення (embed) у твій Discord-канал,
     з посиланнями на обрані платформи.

Прапорець «Надіслати сповіщення в Discord» можна зняти, якщо треба просто
опублікувати новину на сайті без сповіщення. «Позначити @everyone» додає
згадку всіх учасників сервера в повідомленні.

### Якщо Discord не приймає запит

Деякі мережеві/браузерні розширення (адблокери, VPN з фільтрами) можуть
блокувати прямі запити до `discord.com`. Якщо сповіщення стабільно не
надсилаються, найпростіший обхід — зробити маленький безкоштовний проксі
(наприклад, Cloudflare Worker на кілька рядків), який просто пересилає
запит на вебхук. Напиши мені, якщо знадобиться — додам це окремим кроком.
